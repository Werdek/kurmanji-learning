# LINGUISTIC_RESOURCES.md

> **Version:** 0.4 — A1–A2 source ledger and text-first policy  
> **Last updated:** 2026-11-06  
> **Purpose:** Record the authoritative references, verification rules, and source-to-content mapping used to build the A1–B1 Kurmanji curriculum.  
> **Current content status:** A1 and A2 are complete: 460 exercises and 677 lexemes across 12 units, all source-checked against the ledger below (`reviewStatus: "checked"`). There is no native-review gate and no content-audio component. Optional interface tones can be muted. B1 is planned.

---

## 1. Principles

1. **No self-referential translation loops.** Kurdish is never generated by recursively translating an English draft through a model and treating the output as evidence. Every Kurdish string must trace to a grammar, dictionary, corpus, or other citable source.
2. **Source before sentence.** An example sentence is authored only after the target rule and its lexicon have been checked.
3. **One primary source per claim.** Where sources disagree, the conflict is logged and resolved explicitly; it is not silently averaged.
4. **Source checking is the publication gate.** A grammatically possible sentence can still be unnatural, but the course publishes at `reviewStatus: "checked"` after source and schema validation. Native review is optional and does not block publication.
5. **Dialect is metadata, not an afterthought.** Every non-standard form is tagged.
6. **Text-first by design.** The course has no content audio input, listening exercises, microphone capture, or TTS. Evidence comes from written sources and typed learner responses. Optional interface tones are not language content.

|---|---|---|---|

| 1 | Monograph on ergativity | Split ergativity and diachronic variation | Dorleijn 1996 |

| 2 | Kurdish–Kurdish dictionary | Semantic nuance and contemporary usage | Farqînî 2003 |
| 2 | Grammar/dictionary | Cross-check and pedagogical explanation | Rizgar 1993; Thackston vocabulary |
| 2 | Dialectology | Regional variation and baseline decisions | Haig & Öpengin 2018; Öpengin & Haig 2014 |
| 3 | Orthography/reference institution | Spelling, norms, published usage | Institut Kurde de Paris; Hawar journal |
| 3 | Corpus | Authentic collocation, narrative structure, written register | DoReCo Northern Kurdish corpus (transcripts) |
| 3 | Literary text | B1 reading, public-domain or licensed | Ehmedê Xanî, *Mem û Zîn*; Hawar prose |
| 4 | CEFR framework | Proficiency descriptors and assessment design | Council of Europe 2001; Companion Volume 2020 |
| 5 | Optional native-speaker feedback | Naturalness, register, dialect | Named reviewers with consent; not a publication gate |

**Source checking is not a popularity contest.** A native speaker may confirm usage, but a grammatical claim still needs a descriptive source or a clearly labelled variation note. No content is blocked on reviewer availability.

### 4.3 Lexicon citation rule

Every lexeme record must contain at least one of:

- `CHY2003:s.v. <headword>` — primary dictionary entry.
- `RIZ1993:<section/table>` — grammar/dictionary cross-check.
- `FAR2003:s.v. <headword>` — Kurdish–Kurdish nuance.
- `TH2006:Vocabulary:s.v. <headword>` — Thackston’s glossary.

A lexeme may carry more than one source. A contemporary culture-specific item may rely on a citable institutional or native-speaker source; it is marked `checked` after that source is recorded, not blocked on a second reviewer.

### 5.3 Lexical gaps

If a concept has no reliable Kurmanji headword in the core sources:

1. Prefer a paraphrase using verified vocabulary.
2. If a contemporary term is necessary, record its source and mark it `checked`; do not invent a form.
3. Do not invent a calque from English or Turkish and present it as standard.
4. Mark the term as `receptive` until it is attested in a published source.

## 6. Orthography and Dialect Policy

### 6.1 Orthography

- Hawar/Bedirxan Latin alphabet: `a b c ç d e ê f g h i î j k l m n o p q r s ş t u û v w x y z`.
- `ê`, `î`, `û` are meaning-bearing long vowels and are never reduced to `e`, `i`, `u`.
- `ş`, `ç`, `x`, `q` are distinct letters, not digraph variants.
- The course does not use ASCII fallbacks in learner-facing Kurdish.
- Arabic and Cyrillic script appear only in labelled script-awareness notes, not as target forms.

### 6.2 Dialect baseline

- **Productive target:** Standard Literary Kurmanji with an Amed/Diyarbakır reference variety.
- **Receptive exposure:** Qamishli/Syrian and Serhed variants at A2–B1.
- **Badini:** receptive glosses only at B1; not a productive model.
- **Variant logging:** `hûn/hun`, `şem/şemî`, `rûnê/rûne`, `biçim/herim`, `bêm/werim`, `wê/ê` future variants.
- There is no voice baseline to enforce because the course has no content-audio component.

### 6.3 Month names

Month nomenclature is regionally variable. Thackston §9.2 records three systems:

1. French-derived names (`janvîye`, `fevrîye`, …).
2. Semitic/Julian names (`çileya paşîn`, `sibat`, `adar`, `nîsan`, `hezîran`, `tîrmeh`, `gelawêj`, `îlon`, `çiriya pêşîn`, `çiriya paşîn`, `çileya pêşîn`).
3. Traditional Kurdish names (`reşeme`, `avdar`, `gulan`, `tîrmeh`, `gelawêj`, `îlon`, …).

**Policy:** teach one core set productively (the second set is recommended for transparency), and present the others as receptive variants. Do not mark a regional name as “wrong.” A1.2 uses the set `rêbendan, reşemî, adar, avrêl, gulan, hezîran, tîrmeh, tebax, rezber, kewçêr, sermawez, berfanbar`.

## 7. Authentic Texts and Corpora

### 7.1 Corpora

| Resource | Use | Cautions |
|---|---|---|
| DoReCo Northern Kurdish corpus | Narrative transcripts, natural written/colloquial patterns | Check licence; select short, culturally appropriate excerpts; do not use unglossed raw text with beginners |
| *Hawar* archive | Orthographic models; literary prose; cultural texts | Public-domain status varies by jurisdiction; adapt length and gloss |
| *Mem û Zîn* | Classical literary excerpt; cultural unit | Archaic vocabulary; provide glosses and modern paraphrase |
| Licensed contemporary media | B1 news/opinion reading | Verify variety, rights, and editorial framing |

The course uses corpora and media as **reading** sources only. No corpus audio is used, because the product has no listening component.

### 7.2 Text adaptation policy

- B1 texts are adapted to 250–350 words for reading tasks.
- Adaptation is logged: source, adaptation type (abridgement, glossing, simplification), and reviewer.
- Adapted texts retain a link to the source and a note on what changed.
- Literary excerpts preserve original orthography where possible; archaic forms are glossed, not silently modernised.
- No text is used without a rights check.

### 7.3 Cultural content

- Present Kurdish culture as internally diverse; avoid monolithic “Kurdish culture” claims.
- Include Newroz, hospitality, tea culture, family, music, and literature with specific, sourced detail.
- Avoid political advocacy; where texts touch on contested history, provide context and multiple perspectives.
- Do not use sacred or religious texts as language drills without context and respect.

## 8. Text-First Content Policy

### 8.1 No content-audio or native-review dependency

The course does not use:

- recorded content audio;
- browser TTS or any synthetic speech;
- listening or dictation exercises;
- microphone capture or ASR;
- a native-review gate for publication.

Optional interface tones are a decorative UI layer, not course content. They confirm correct/incorrect answers and lesson completion, are generated locally with the Web Audio API, and can be muted.

This is a deliberate product decision. It removes recording, licensing, loudness, pronunciation-QA, and reviewer-scheduling work from the critical path.

### 8.2 What replaces audio

| Audio-era activity | Text-first replacement |
|---|---|
| Listening to a dialogue | Read the dialogue with a visible transcript and comprehension items |
| Dictation | Fill-in-the-blank and spelling items with the Kurdish character palette |
| Pronunciation drill | Written descriptions of sounds and stress; optional external audio |
| Recorded role-play | Written dialogue completion and sentence building |
| Listening comprehension test | Reading comprehension and language-use items |

### 8.3 Optional external practice

At A2–B1 the course may recommend external Kurmanji media for optional listening practice. These recommendations are clearly outside the assessed course and do not carry completion or mastery credit.

### 8.4 UI sound cues

Correct/incorrect feedback is visual and textual first. The app may also play short, quiet synthesized tones for correct answers, wrong answers and lesson completion. These cues:

- are optional, on by default, and controlled from Settings or the lesson header;
- are generated locally and make no network requests;
- never carry language content, so no exercise depends on hearing them;
- are skipped automatically when Web Audio is unavailable.

## 10. Verification Workflow and Statuses

### 10.1 Status definitions

| Status | Meaning | Publishable? |
|---|---|---|
| `draft` | Author-created; no source check | No |
| `checked` | Grammar/dictionary check and schema validation complete | Yes |
| `native-reviewed` | Optional native speaker has reviewed naturalness/register | Yes |
| `verified` | Source check plus optional native review complete | Yes |
| `rejected` | Source conflict or unacceptable quality | No |

A1 publishes at `checked`. The status vocabulary is retained so later review can raise a string without a schema change.

### 10.2 Workflow

```
Author draft
   │
   ├─► Source check (TH/CHY/RIZ/BED/FAR)
   │       └─► conflict? → log + resolve → re-check
   │
   ├─► Schema/answer-key validation
   │
   ├─► Cross-reference validation (lexemes, grammar, targets, IDs)
   │
   └─► checked → publish
          │
          └─► optional later native review → native-reviewed / verified
```

### 10.3 Conflict resolution

When sources disagree:

1. Record both forms with source refs.
2. Determine whether the difference is dialect, register, or genuine disagreement.
3. If dialect: tag both; choose the standard literary form for production and the other for receptive exposure.
4. If register: teach the neutral form first; mark the formal/literary form.
5. If genuine disagreement: prefer the more recent descriptive source for usage, but do not overrule a clear normative source without a note.
6. Add the case to the conflict log; never silently edit.

## 11. Prohibited and Rejected Sources

The following are **not** acceptable as primary evidence for Kurdish content:

- Google Translate, DeepL, or any machine translation output.
- Recursive LLM translation chains.
- Glosbe, Tatoeba, or unverified user-generated sentence collections.
- Social-media posts, comment sections, or uncredited memes.
- Wiktionary as a primary grammar authority (usable only as a discovery pointer).
- AI-generated “native speaker” personas.
- Unlicensed copyrighted textbooks or dictionaries.
- Any source that cannot be cited with a stable title, author, and edition.

A candidate source may be used for **discovery** (finding a word or construction) but never as the final citation.
